# 말풍선 버전 V5

V4의 원본 소재와 독립 모션을 유지하고 대사 표기만 변경했다.

| 장면 | 표시 |
|---|---|
| 1 | 캡슐 아래 말풍선: 우주에선 물이 어떻게 움직일까? |
| 2 | 타워 오른쪽 말풍선: 여기서 먼저 알아보자! |
| 3 | 캡슐 왼편 말풍선: 함께 떨어지면… — 캡슐과 함께 낙하 |
| 4 | 캡슐을 향한 말풍선: 어? 물방울이 떠 있네! |
| 5 | 플레이트 왼편 말풍선: 이 움직임을 기록하자! |
| 6 | 상단 중앙의 큰 문구: 우주 기술, 지구에서 먼저! |

말풍선은 원본 이미지에 덧그린 파일이 아닌 별도의 Remotion SVG 레이어다.
배치와 줄바꿈은 `public/assets/motion-v4/dialogue-v5.json`에 저장했다.
기존 V4 영상과 자막 모드는 보존했다.

`npm run render:v5`로 `deliverables/webtoon-v5-15s.mp4`를 렌더링한다.
1920×1080, 30fps, 450프레임, 정확히 15초, 무음 H.264 MP4다.
`webtoon-v5-download.zip`에는 영상, 이 설명과 검증 결과가 들어 있다.
