# 영상용 분리 소재

원본 8장은 `public/assets/`에 그대로 유지했습니다. 원본 파일 SHA-256은 Git에 저장된 원본과 모두 일치합니다. 본편 영상 및 음성은 제작하지 않았습니다.

## 표정 파일과 정렬

- 캡슐: `happy`, `thinking`, `worried`, `surprised`, `wink`
- 드롭타워: `happy`, `pointing-wink`, `celebrating`
- 접시 마스코트: `smile`, `excited`, `thinking`, `worried`, `confident-wink`

| 종류 | 공통 PNG 캔버스 | 몸체 기준점 (x,y) | 정규화 몸체 크기 |
| --- | --- | --- | --- |
| 캡슐 | 560×768 | (280,716) | 330×660 |
| 드롭타워 | 640×768 | (320,720) | 293×669 |
| 접시 | 720×520 | (330,418) | 460×283 |

기준점은 몸체의 중앙 하단입니다. 접시는 원통 몸체 하단을 기준으로 하므로 발은 그 아래로 나옵니다. 팔·발·표정 효과의 바운딩 박스는 정렬 기준에서 제외했습니다. 몸체 크기를 맞추는 과정에서 캐릭터는 리샘플링했으며, 표정별 원본 포즈와 장식의 차이는 유지했습니다. 같은 종류의 표정은 동일한 PNG 표시 크기와 위치로 교체하세요. 파일마다 자동으로 투명 여백을 다시 자르면 정렬이 깨집니다.

## 소품

`props/`에는 다음 8개 PNG가 있습니다.

- `water-drop-round.png`: 구형 물방울
- `water-drop-long.png`: 길쭉한 물방울
- `pipette.png`: 끝에 달린 작은 물방울을 포함한 피펫
- `chamber.png`: 투명 실험 챔버
- `camera.png`: 받침대를 포함한 카메라
- `monitor.png`: 받침대를 포함한 모니터
- `thought-bubble.png`: 꼬리의 작은 원 두 개와 내부 그림을 포함한 생각풍선
- `water-tank.png`: 상하 연결부를 포함한 물탱크

물방울은 두 형태를 모두 보존해 요청한 7종을 8개 파일로 제공합니다. 소품은 크기를 변경하지 않고 잘라 투명 여백 24px을 추가했습니다.

## 투명도와 품질 확인

외부의 낮은 알파 배경 흔적과 분리된 잡점을 제거했습니다. 물체 내부의 원본 RGBA는 유지했고, 챔버의 반투명 유리·반사광·내부 볼트와 물방울의 반사광을 보존했습니다. 손·안테나·놀람 표시·반짝임·생각풍선 꼬리를 포함했습니다. 캐릭터의 크기 정렬에 따른 가장자리 리샘플링 외에 재생성하거나 다시 그리지 않았습니다.

- 원본 8개 파일 해시 일치
- 이미지 25개 PNG 검증 (배경 4 + 캐릭터 13 + 소품 8)
- 투명 PNG 21개 모두 캔버스 가장자리에서 최소 12px 이상 여유
- 실제 원본 윤곽과 떨어진 표정 효과가 자르기 영역에 포함되는지 검사
- 밝은 배경/어두운 배경 전체 미리보기와 상세 미리보기 육안 확인

`preview-all.png`: 전체 결과. 각 투명 소재는 밝은/어두운 배경에 두 번 표시됩니다. 붉은 십자는 미리보기 전용 정렬 표시이며 개별 PNG에는 없습니다.

`preview-details.png`: 챔버 투명도, 물방울 반사광, 반짝임, 안테나와 손의 상세 확인.

`manifest.json`: 원본 파일명, 원본 자르기 좌표, 몸체 정렬 좌표, 알파 통계, 원본 해시.

`quality-report.json`: 파일별 투명 여백과 알파 범위 검사 결과.

## Remotion에서 사용

설치된 `remotion-markup`의 `images.md`/자산 지침에 따라 `public` 아래의 파일을 `staticFile()`로 참조합니다. 예를 들어 `staticFile('assets/extracted/characters/capsule/happy.png')`를 사용할 수 있습니다. 표정 교체 때 공통 캔버스 크기 및 위치를 유지하고 `objectFit: 'contain'`으로 전체 PNG를 표시하세요.

재분리 스크립트: 프로젝트 루트의 `tools/extract_assets.py` (Pillow, NumPy, SciPy 사용).
